# AllInOneMod

《觅长生》多合一功能整合 Mod，包含多个实用功能，可通过配置文件独立开关。

## 功能列表

- **NPC背包排序**：打开NPC背包时自动按整理功能排序。
- **闭关突破排序**：突破界面功法按突破层数和品级排序。
- **宗门任务复制**：宗门长老发布任务列表添加复制按钮，快速复制任务。
- **交易会快捷键和复制**：按H键打开交易会，交易会列表添加复制按钮。
- **天衍阁传音预告**：任务追踪面板显示天衍阁寻物传音送达时间。
- **显示闭关预计日期**：闭关修炼时显示预计完成日期。
- **修复Steam成就问题**：修复吸血技能负伤害导致总计造成伤害成就异常。
- **合并重复消息提示**：合并短时间内重复的右侧消息提示，避免刷屏。
- **技能伤害预测**：鼠标悬停伤害技能时显示预测伤害。
- **常驻回合数显示**：战斗中常驻显示当前回合数。
- **去除无尽海迷雾**：去除无尽海地图上的迷雾遮罩（默认关闭）。

## 安装方法

1. 确保已订阅 **BepInEx** 等前置框架。
2. 在 Steam 创意工坊订阅本 Mod。
3. 启动游戏后，配置文件会自动生成。

## 修改与编译

如需自行修改代码：

1. 克隆本仓库。
2. 使用 Visual Studio 打开 `AllInOneMod.sln`（或对应的 `.csproj`）。
3. 修改代码并编译，将生成的 `AllInOneMod.dll` 放入 `BepInEx/plugins/` 文件夹。

## 配置文件

路径：`BepInEx/config/Yueyehuiling.MCS.AllInOneMod.cfg`

各功能均可在配置文件中独立开关，修改后重启游戏生效。

如果安装了 **BepInEx 插件管理器（ConfigurationManager）**，可以在游戏内按 `F1` 直接修改配置，无需手动编辑文件。

## 快捷键
