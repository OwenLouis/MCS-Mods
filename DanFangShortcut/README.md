# DanFangShortcut

《觅长生》炼丹界面丹方快捷保存与加载 Mod，可在炼丹时快速切换常用丹方。

## 功能列表

- **丹方保存**：在炼丹界面按 `Ctrl+1~9` 保存当前丹方到对应槽位。
- **丹方加载**：在炼丹界面按 `1~9` 快速加载已保存的丹方。
- **自动识别名称**：保存时自动识别当前丹方名称并作为默认名称。
- **自定义命名**：保存时可手动输入丹方名称。
- **稀有药材标记**：可在配置文件中标记稀有药材ID，计算炼制次数时优先考虑稀有药材。
- **炼制次数预估**：加载丹方时自动计算当前材料可炼制次数，并显示缺料清单。

## 安装方法

1. 确保已订阅 **BepInEx** 等前置框架。
2. 在 Steam 创意工坊订阅本 Mod。
3. 启动游戏后，配置文件会自动生成。

## 修改与编译

如需自行修改代码：

1. 克隆本仓库。
2. 使用 Visual Studio 打开 `DanFangShortcut.csproj`。
3. 修改代码并编译，将生成的 `DanFangShortcut.dll` 放入 `BepInEx/plugins/` 文件夹。

## 配置文件

路径：`BepInEx/config/Yueyehuiling.MCS.DanFangShortcut.cfg`

可在配置文件中设置稀有药材ID列表（用英文逗号分隔）。

如果安装了 **BepInEx 插件管理器（ConfigurationManager）**，可以在游戏内按 `F1` 直接修改配置，无需手动编辑文件。

## 快捷键

| 按键 | 功能 |
|------|------|
| `Ctrl+1~9` | 保存当前丹方到对应槽位 |
| `1~9` | 加载对应槽位的丹方 |
| `Ctrl+0` | 查看历史消息 |
