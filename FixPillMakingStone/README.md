# FixPillMakingStone

修复原mod 黑市商人附属-炼丹石 中的 炼丹石-时间 未生效的补丁。
原mod链接：https://steamcommunity.com/sharedfiles/filedetails/?id=2825157272

## 说明
本 Mod 为独立 DLL 替换/补丁，直接放入 xxx\Steam\steamapps\workshop\content\1189490\2825157272\plugins\ 下覆盖原文件。

## 安装
1. 确保已安装 BepInEx和黑市商人附属-炼丹石mod
2. 将 `pillMakingStone.dll` 放入 `xxx\Steam\steamapps\workshop\content\1189490\2825157272\plugins\` 下覆盖原文件
3. 启动游戏

## 来源
本文件基于原mod `pillMakingStone.dll` 修改。
